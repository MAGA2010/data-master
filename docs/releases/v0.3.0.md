# data-master v0.3.0

This release makes reports easier to share and expands the public evidence for
ambiguous and survey-shaped data.

## Highlights

- Every full and profile-only analysis now includes a self-contained HTML report.
- A date-versus-number benchmark proves ambiguous values are held instead of guessed.
- A synthetic survey case study covers labelled categories, missing-value codes and zero-padded identifiers.
- Rank-based omnibus tests now include a bootstrap interval for epsilon squared.
- Report language is derived from the observed results and no longer upgrades null findings.
- Distribution validation now includes macOS with Python 3.13.
- The full install, analysis and verification path was independently exercised in ZCode 3.14.4 on Windows.

## Quick start

```bash
npm install -g github:MAGA2010/data-master#v0.3.0
data-master setup
data-master skill install
data-master demo --out outputs/first-demo
```

The release includes a Python wheel, npm tarball, portable `.skill` archive and
SHA-256 checksums. See the repository README for the evidence contract and
supported inputs.
