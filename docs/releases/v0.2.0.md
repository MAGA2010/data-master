# data-master v0.2.0

The first public release turns a raw dataset into a reproducible Markdown and
PDF report with an inspectable evidence trail.

## Highlights

- Unit-aware group comparisons avoid counting repeated rows as independent samples.
- Cleaning plans preserve raw inputs, record every conversion and replay byte-for-byte.
- Sensitivity analysis and an eight-gate audit keep uncertainty and unresolved decisions visible.
- Resume verifies artifact hashes and rebuilds stale downstream stages.
- Windows and Linux CI cover Python 3.11–3.13.
- Install the CLI from GitHub through npm or a Python wheel.
- Install the Codex skill with `data-master skill install`.

## Quick start

```bash
npm install -g github:MAGA2010/data-master#v0.2.0
data-master setup
data-master skill install
data-master demo --out outputs/first-demo
```

The release includes a Python wheel, an npm tarball, a portable `.skill`
archive and SHA-256 checksums. See the repository README for supported inputs,
current limitations and the full evidence contract.
