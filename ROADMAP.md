# Roadmap

The roadmap is driven by successful external analyses, not feature count.

## Now: first 50 users

- Make install-to-first-report reliable in under five minutes.
- Publish three reproducible case studies with inspectable artifacts.
- Add macOS distribution coverage.
- Collect the first ten external dataset reports and document setup failures.
- Validate the skill in one additional Agent Skills-compatible environment.

## Next: 50–200 users

- Add a shareable HTML evidence report.
- Publish a benchmark corpus of dirty and statistically deceptive datasets.
- Complete an independent statistical-method review.
- Add a safe skill update command with rollback.
- Improve Excel workbook and survey-data workflows based on reported demand.

## Later: 200–1,000 users

- Publish stable registry packages after package names and maintenance ownership are settled.
- Add a hosted, privacy-preserving demo with synthetic data.
- Translate the quick start with community maintainers.
- Establish a regular release cadence and maintainer group.

## Contribution-sized tasks

The following tasks are intentionally small enough for a first contribution:

1. Add a macOS Python 3.13 distribution job and document platform-specific failures.
2. Add an HTML export for the existing Markdown report without changing numerical content.
3. Add a survey-data case study with labelled values and missing-value codes.
4. Add a benchmark fixture for an invalid date/numeric ambiguity.
5. Validate installation in one additional Agent Skills-compatible client and document only observed behavior.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) before changing statistical decisions.
